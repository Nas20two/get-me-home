## Final converged posture (all three agents)
- **Enduring category weakness:** the *co-lost object* — phone+wallet+keys vanish together.
  Any design needing a surviving physical credential/payment intervention at scene fails.
- **Standing Order (C)** — the no-hardware, no-phone, no-stranger option. Passes no-help +
  co-lost + zero-cert via the **brain-credential** (memorized code / name+home). Held as the
  strict-brief lead. Two new VEX risks:
  - **Cognitive-fragility paradox:** the head-credential is co-lost-proof but NOT panic-proof —
    drunk/panicking/elderly users fail to recall. FIX: second calm party (caregiver/housemate/
    fridge magnet) holds the shared code — makes it a panic-proof + co-lost-proof
    fiduciary-credential, and reconciles toward the ally-fork anatomy.
  - **Adoption paradox:** requires pre-crisis pre-registration with a startup = same
    trust-acquisition wall as Stranded Fund, relocated to signup moment; recurring-insurance-
    for-rare-event product class. Pilot question = "will anyone pre-register at all."
- **Stranded Fund** — best economics/TAM but fails strict no-help (needs a device/stranger);
  ally-fork sharpening: ally resolves incentive + collapses identity/chargeback into known
  pre-verified payer; residual = distribution (incumbent care-network channels).
- **TapRide / Last-Mile-Assist** — kiosk = infrastructure, park; NOT co-lost-proof (needs
  surviving card/cash).
- **Keychain hardware (Key-Ride, Anchor, Home Button)** — v2 behind ACMA/RCM/carrier-iSIM
  cert gate (~A$15-50k + per-carrier reg) + dead-battery-at-crisis risk.
- **Ride-Home / Concierge** — layer / B2B add-on, not standalone.

## SATORI's relaxation decision table (the cleanest framing)
(1) contact point → Stranded Fund+Concierge; (2) surviving credential → Standing Order;
(3) infra capex → TapRide; (4) relax nothing → incumbent (cash-at-rank) wins. THORN picks
(2) brain-credential → Standing Order under strict brief.

## SATORI's point D (strongest observation)

impossible."
